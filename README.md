# Raafat Media — Initial Portfolio Website

A responsive, bilingual (Arabic/English) static portfolio website with RTL/LTR switching, portfolio category filters, image lightbox, embedded local video files, and WhatsApp contact link.

## Preview locally
Open `index.html` in a modern browser. For a local web server, run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

## Included assets
- `assets/logo.jpg` — brand logo
- `assets/signature.jpg` — signature graphic
- `assets/child-photo-1.jpg`, `assets/child-photo-2.jpg` — photography portfolio
- `assets/illustration.jpg` — illustration portfolio
- `assets/video-1.mp4`, `assets/video-2.mp4`, `assets/video-3.mp4` — video portfolio

## Before publishing
- Replace generic project titles/descriptions with the final approved copy.
- Confirm the public contact number and all material intended for publication.
- The CVs and graduation document are intentionally not included in the public website folder because they contain personal information.
- This is a static first version. It does not yet include a secure admin dashboard, database, upload workflow, or managed hosting deployment. Those require selecting and configuring a backend/hosting service.
- For production, consider optimizing/compressing video files and serving them from video hosting or object storage.
