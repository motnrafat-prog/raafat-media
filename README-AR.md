# Raafat Media — الموقع ولوحة الإدارة

## ما الموجود في هذه الحزمة؟
- `index.html`: الموقع العام.
- `admin.html`: لوحة إدارة مع تسجيل دخول، إضافة/تعديل/حذف المشاريع ونشرها أو حفظها كمسودات.
- `config.js`: مكان إعداد Project URL وPublishable key فقط.
- `supabase-storage-setup.sql`: إعداد مساحة رفع الصور والفيديو وسياساتها.
- `assets/`: أصول الموقع العامة.

## مهم قبل النشر
1. افتح `config.js` واستبدل `PASTE_PROJECT_URL_HERE` بعنوان مشروع Supabase، واستبدل `PASTE_SB_PUBLISHABLE_KEY_HERE` بمفتاح `sb_publishable_...` من إعدادات المشروع.
2. لا تضع أبدًا `service_role` أو Secret key في أي ملف يصل إلى المتصفح.
3. في Supabase SQL Editor، نفّذ محتوى `supabase-storage-setup.sql` مرة واحدة لإنشاء مساحة `project-media` وسياسات الملفات. إعداد جدول `projects` وقائمة `admin_users` ودالة `is_admin()` يجب أن يكون قد نُفّذ بالفعل.
4. تأكد أن معرّف المستخدم الصحيح موجود في `public.admin_users` وأن الحساب يستطيع تسجيل الدخول.
5. ارفع **محتويات هذا المجلد** إلى جذر مستودع GitHub، وليس ملف ZIP نفسه. انتظر اكتمال نشر Netlify.
6. افتح `https://YOUR-SITE/admin.html` وسجّل الدخول بحساب Supabase الذي أضفته. لا تشارك رابطًا خاصًا أو كلمة مرور؛ تذكّر أن `admin.html` قد يكون مرئيًا للجميع، لكن إجراءات الإدارة محمية من جهة قاعدة البيانات.

## ملاحظات
- الملفات المرفوعة إلى bucket `project-media` عامة للعرض، لأنها أصول محفظة أعمال عامة. صلاحية الرفع والتعديل والحذف مقيدة بسياسة `public.is_admin()`.
- لوحة الإدارة لا تجعل الحساب مديرًا بمجرد تسجيل الدخول؛ يجب أن يطابق `auth.uid()` صفًا في `admin_users`.
- لا ترفع السيرة الذاتية أو شهادة التخرج أو أي مستندات شخصية إلى مستودع عام.
- إذا كانت إعدادات SQL السابقة تختلف عن المتوقّع أو ظهرت رسالة خطأ، توقّف وأرسل نص الخطأ فقط قبل تعديل السياسات.
